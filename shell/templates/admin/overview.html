Deploy the first app

From a terminal: connect the appos CLI to this platform once, then deploy from the app's folder.

appos login {{ s.url }}
appos new hello && cd hello
appos deploy

It shows up here with its requests, versions and risk. From the app's folder, appos versions then tells what happened to each version, and appos log why a request failed.
